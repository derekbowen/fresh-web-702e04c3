# Untyped content pages: sitemap classification (2026-11-15)

`content_pages` rows with `template_type IS NULL` are emitted by no sitemap route
(`.in("template_type", [...])` never matches NULL). They still render through the
`/p/$slug` dispatcher's generic template. A published row is **not** enough to list a
page: each group below was checked against the live site and against the other
sitemaps before anything was included.

Sources: read-only SQL on the production project (2026-11-15), the audit crawl of every
sitemap URL (2026-11-14, `crawl.jsonl`), and live GETs on 2026-11-15 (one request at a
time, 0.6 s apart).

## Included

### `elearning-academy-*` (131 rows) → `sitemap-pages-academy.xml`

- Already advertised on www: all 131 are in the static WEST academy file
  (`/sitemap-pages-academy.xml` on www, frozen 2026-07-20). The app route did not emit
  them, so proxying that path to the app (see `academy-sitemap.md`) would have dropped
  them. Including them keeps the app route a complete replacement. No other sitemap
  lists them.
- Crawl of 2026-11-14: 131 of 131 answer 200, no robots meta, no `X-Robots-Tag`,
  canonical equal to the URL. Rendered words 1,802 to 2,291 (median 1,984).
- Not duplicates: 131 distinct titles; no `body_markdown` equal to another untyped row
  or to any of the 70 typed `elearning` rows (md5 compare); no H1 shared with any other
  sitemap page in the crawl. 40 are Spanish (`-es`), none is a translation twin of a
  typed row by slug.
- Bodies 10,527 to 13,456 characters, so the academy group's 800-character floor keeps
  all of them.
- Rule: `template_type IS NULL AND slug LIKE 'elearning-academy-%'`
  (`untypedSlugPrefixes` in `src/lib/sitemap-groups.ts`). If a row later gets a
  template type, it moves to that type's group and leaves this rule.
- Not reviewed: the course text itself. Three of these courses are about insurance and
  claims (`...homeowners-insurance-gaps-why-your-policy-wont-cover-paid-rentals`,
  `...damage-control-navigating-insurance-claims-repairs`,
  `...seguro-y-cobertura-de-responsabilidad-es`). They are already advertised on www
  today; this change does not add them to www. See "Open decisions".

### `academy-catalog` → `sitemap-pages-academy.xml`

the WEST academy file. The academy hub for the courses above.

## Excluded

### Redirect rows (163: 69 Peerspace, 52 Giggster, 9 swim, 33 other)

Every row has `redirect_to` set, so the dispatcher (or the comparison route) answers
301. The base sitemap filter already drops `redirect_to IS NOT NULL`. Live samples:
`/p/peerspace-vs-pool-rental-near-me-in-murrieta` and
`/p/giggster-vs-pool-rental-near-me-in-elmendorf-tx` → 301
`/p/swimply-alternative-vs-pool-rental-near-me`;
`/p/swim-instructor-pool-rental-sacramento` → 301 `/s`;
`/p/swim-instructor-pool-rental-durham-ct` → 301
`/p/become-a-swimming-pool-host-durham-ct`; `/p/kirkland` → 301 `/s`.

The comparisons sitemap generates `/p/{giggster,peerspace}-vs-pool-rental-near-me-in-<city>`
from the `cities` table, not from these rows. 96 of the 121 comparison rows name a
published city; that sitemap already skips exactly those 96 URLs because they redirect.
The other 25 name no published city and are generated by nothing.

### `billings-mt`, `biloxi-ms`, `bethesda-md`

200 and self-canonical, but about 205 words, `body_markdown` about 715 characters, the
H1 printed twice, and each city already has a typed, listed host page
(`/p/become-a-swimming-pool-host-billings-mt` etc.). Listing them would add three thin
near-duplicates of listed pages.

### `how-hosting-works`

200 and self-canonical, 213 words, two H1s. Covers the same ground as `/p/hosting` and
`/p/how-it-works`, which are both listed.

### `prnm-facts` (`url_path` NULL)

200 and self-canonical, 522 words, but the page states a "10%" fee six times (for
example "10% (founding hosts are grandfathered)"). The fee is 15% to guests and 0% to
hosts. Not advertised until the copy is corrected (audit fix F14).
